# 项目检索信息 / Project discovery

仓库名称：**music-creation-toolkit**。GitHub About 使用中英文说明，topics 描述实际技术与用途。中文入口为 `README.md`，英文入口为 `README.en.md`；两者互链，首段说明音乐创作、Tone.js / Web Audio、Python DSP、采样、循环和离线导出。

Repository discovery uses a descriptive name, a bilingual About description, factual GitHub topics, linked Chinese/English READMEs, package metadata and machine-readable audio metadata. The project is a public GitHub template so other creators can start their own repositories.

声音索引的中英文名称、音色族、MIDI 根音、BPM、调性与 tags 供本地搜索与工具处理；SHA-256 和许可链接帮助核查。新增资产后运行 `npm run assets:catalog`，以免目录落后。

这些措施提高信息完整度和可检索性，不保证搜索排名、曝光量或平台推荐。The metadata improves clarity and searchability, without guaranteeing rankings or recommendations.
